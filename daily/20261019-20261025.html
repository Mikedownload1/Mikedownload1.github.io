[arXiv261019] Scalable Levenberg-Marquardt Training Framework for Deep Learning

arXiv
mlsysothersLevenberg-Marquardt algorithm, distributed training, dual formulation, Jacobian sharding, multi-GPU, second-order optimization, Gauss-Newton
Authors
Xianghao Wang, Johan Barthélemy, John Taylor
Institution
Australian National University, NVIDIA

The paper proposes LeMA, a distributed Levenberg-Marquardt algorithm for large-scale neural network training on multi-GPU platforms. It uses an exact dual formulation that removes memory dependence on parameter dimension and a Jacobian sharding strategy that computes shards on the fly in parallel, reducing memory from quadratic in parameters to quadratic in batch size. This enables exact LMA steps for billion-parameter models, achieving a 7.97x speedup over a single GPU with 99.7% strong scaling efficiency on an 8-GPU node.

[arXiv261019] Fast Distributed -Edge Coloring in Bipartite Graphs

arXiv
sysdistributed graph algorithms(Δ+1)-edge coloring, bipartite graphs, LOCAL model, deterministic algorithms, local-palette coloring, Vizing's theorem, distributed computing
Authors
Yann Bourreau, Sebastian Brandt, Ananth Narayanan
Institution
CISPA Helmholtz Center for Information Security

The paper studies deterministic distributed (Δ+1)-edge coloring on bipartite graphs in the LOCAL model. It shows that this can be solved in O(f(Δ) log n) rounds for some function f, which implies O(log n) rounds for constant-degree bipartite graphs, improving prior bounds with much larger n-dependencies. The results also hold for a more restrictive local-palette version of the problem, and vertices need not know their side of the bipartition.

[arXiv261019] MailRail: Mitigating Incast Congestion with User-Space, Node-Based Flow Control

arXiv
mlsyscluster infrastructureincast congestion, credit-based flow control, node-based credit accounting, user-space flow control, asynchronous messaging, Graph Neural Networks, Mixture-of-Experts
Authors
Noel Gomillion, Lance Fletcher, Trevor Steil, Eun Jung Kim, Roger Pearce
Institution
Lawrence Livermore National Laboratory, Texas A&M University

The paper introduces MailRail, an out-of-order asynchronous messaging framework with a user-space, node-based credit flow control system designed to mitigate incast congestion in large-scale parallel workloads such as GNNs and MoE models. By pooling transmission credits at the shared per-node level rather than per-rank, it maintains usable credit availability as process density grows and allows dynamic reuse of freed credits. Experiments show up to a 1132x speedup over unconstrained execution at an adversarial 4096:1 incast ratio while adding minimal overhead on uniform workloads.

[arXiv261019] The LLM-Attacker: A Unified Red-Team Framework for Privacy Evaluation of Split and Distributed LLM Systems

arXiv
mlsysllm inferencesplit learning, privacy evaluation, red-team framework, reconstruction attacks, activation leakage, gradient leakage, GPT-2, benchmark reproducibility
Authors
Georgios Politis, Evangelos Pappas
Institution
Setloop.io

The paper presents LLM-Attacker, a unified red-team framework for recording, comparing, and extending privacy evaluations of split and distributed LLM systems, where attacks reconstruct input text from intermediate activations and gradients. The framework requires a linked undefended reference before a defence can pass and explicitly reports untested attacks. In a controlled GPT-2 experiment, adding gradients to attacker observations raised token recovery from 94.20% to 97.38% and exact-document recovery from 13.71% to 37.77%, showing that recorded attacker access choices strongly affect measured privacy.

[arXiv261019] TCDA: Tunable Coded Distributed Arrays for Data Availability Sampling

arXiv
sysblockchain networks and distributed storagedata availability sampling, tunable coded distributed arrays, network coding, Byzantine fault tolerance, erasure codes, peer-to-peer storage, robust distributed arrays, PUT/GET protocols
Authors
Duc A. Tran, Dung Truong, Duy Le
Institution
University of Massachusetts Boston

The paper proposes TCDA, a coded networking layer for data availability sampling that remains provably robust against any number of Byzantine peers as long as enough good nodes exist, with a tunable knob controlling how much assigned data each node stores. Tuning this knob trades PUT and storage costs against GET cost, and can be adjusted per data type as the good-node population changes. Evaluations at Ethereum's parameters show TCDA meets the attestation deadline from 868 up to 40,000 good nodes while storing 1.7–32× less per node than full replication, at the cost of 2.5–7.7 round-trips per sample.

[arXiv261019] TRACE: Transformer Residual Activation Codebook Encoding for Communication-efficient Distributed Edge Inference

arXiv
mlsysllm inferencedistributed inference, sequence parallelism, vector quantization, codebook encoding, Transformer, hierarchical clustering, communication-computation overlap, edge computing, activation compression
Authors
Muhammad Azlan Qazi, Alexandros Iosifidis, Qi Zhang
Institution
Aarhus University, Tampere University

TRACE is a framework for communication-efficient distributed Transformer inference that places a vector quantizer at the post-attention residual of each layer and precomputes codebook-indexed key/value representations, so receivers can recover keys and values via table lookup instead of downstream projection, enabling communication-computation overlap. A hierarchical codebook clustering further allows runtime bitrate adaptation without retraining, with two operating variants for accuracy versus efficiency. Experiments on ViT-Base and ViViT-B show up to 1.89% higher accuracy, up to 1.27x speedup over a state-of-the-art VQ-based distributed inference framework, and up to 22,624x reduced communication overhead versus uncompressed sequence-parallel inference.

This paper characterizes KV cache residency across four production Microsoft M365 agentic LLM workload traces covering over 121 million model calls, showing that reusable KV state is large, long-lived, and mostly idle. Authors

Institution

QuarkShard proposes a sharding blockchain protocol that decomposes cross-shard user requests into single-input-shard transactions, each processed by consensus within only one shard, which lowers intra-shard BFT and cross-shard communication overheads below conventional lower bounds. Evaluation across four AWS regions shows peak throughput of 1024k requests per second with sub-4-second latency, reaching up to 210.7% and 314.8% of Kronos and 2PC maximum throughputs.

TALLOP jointly optimizes local training workload and communication compression under per-round time constraints to minimize time-to-accuracy in heterogeneous federated learning. ScaleRAN is a node-local runtime that leverages NVIDIA Green Contexts to dynamically partition GPU Streaming Multiprocessors between latency-critical RAN workloads and co-located AI workloads through a ladder of pre-created partitions at RAN slot granularity. The paper studies alternation hierarchies for distributed decision in anonymous networks where a prover and disprover alternately assign constant-size certificates over a constant number of rounds, considering SET, MULTISET, and PORTS models that differ in neighborhood information available to the verifier. The paper models multi-chain EIP-1559 fee markets as a nonlinear dynamical system with delayed feedback and identifies delay-amplified over-correction as the structural cause of instability.
